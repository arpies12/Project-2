# ClickWithMe

ClickWithMe is a personal portfolio website designed to showcase various works and provide information about the creator. The site includes sections for Home, Work, About, and Contact. It uses Bootstrap for responsive design, Font Awesome for icons, and custom CSS for styling.

## Features

- **Home Page**: Features a background image and a logo for visual appeal.
- **Work Page**: Displays a gallery of images showcasing different works with clickable thumbnails.
- **About Page**: Provides details about the creator and the story behind their pictures.
- **Contact Page**: Includes a contact form for users to send messages and request a copy of their message.

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- Font Awesome
- Custom CSS
